Row click → opens Screen 2 for that recruit. Sorting/filtering by readiness lets you jump straight to anyone who's hard-sell-ready without opening each recruit individually — this is the "scan the whole board at a glance" view. Pipeline (1–5) is a flat, editable-anytime grade per state — not attached to a recruit, a season, or a program. Clicking the dots on an "Unset" state lets you grade it right there; the value then just shows up for every future recruit from that state until you change it. Because it isn't tied to the annual recruit data, wiping last year's class doesn't touch it.
